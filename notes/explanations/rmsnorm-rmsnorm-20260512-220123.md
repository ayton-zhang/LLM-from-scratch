# [rmsnorm] rmsnorm 代码解释笔记

## 原始代码
```python
class RMSNorm(nn.Module):
    """Root Mean Square Layer Normalization.
    y = x * g / rms(x),   rms(x) = sqrt(mean(x^2) + eps)
    """
    def __init__(self, dim: int, eps: float = 1e-8):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        rms = x.pow(2).mean(dim=-1, keepdim=True).add(self.eps).sqrt()
        return (x / rms) * self.weight
```

## 语法用法
`RMSNorm` 继承 `nn.Module`，这是 PyTorch 自定义层的标准写法。`super().__init__()` 会初始化父类并完成参数注册机制，否则该层中的参数不会被正确追踪。

`self.weight = nn.Parameter(torch.ones(dim))` 的作用是定义一个可训练参数向量，初始值为 1。`nn.Parameter` 和普通 `Tensor` 的区别是：它会自动出现在 `model.parameters()` 中，被优化器更新。

在 `forward` 里，`x.pow(2).mean(...).add(...).sqrt()` 是链式张量操作。`keepdim=True` 用于保留被归约维度，便于后续广播。返回语句 `(x / rms) * self.weight` 先做归一化，再做可学习缩放。

## 维度解读
设输入为 `x`，形状是 `(B, T, C)`：
- `B`：batch size
- `T`：序列长度
- `C`：特征维度（通常等于 `dim`）

关键中间变量形状变化如下：
1. `x.pow(2)`：形状不变，仍是 `(B, T, C)`
2. `.mean(dim=-1, keepdim=True)`：沿最后一维 `C` 求均值，变为 `(B, T, 1)`
3. `.add(self.eps).sqrt()`：逐元素操作，形状仍为 `(B, T, 1)`，记为 `rms`
4. `x / rms`：广播除法，`rms` 从 `(B, T, 1)` 广播到 `(B, T, C)`，输出为 `(B, T, C)`
5. `(x / rms) * self.weight`：`self.weight` 形状是 `(C,)`，按最后一维广播到 `(B, T, C)`，最终输出为 `(B, T, C)`

这里没有 `view/reshape`、`transpose/permute`、`matmul/attention`，但有两次关键广播对齐：
- `(B,T,1)` 与 `(B,T,C)` 的按最后维广播
- `(C,)` 与 `(B,T,C)` 的按特征维广播

## 代码逻辑
该层实现 RMSNorm（Root Mean Square Normalization）。首先对每个位置的特征向量计算 RMS：

$$
\mathrm{rms}(x)=\sqrt{\mathrm{mean}(x^2)+\epsilon}
$$

然后用输入除以 RMS 完成幅值归一化，再乘可学习参数 `weight` 做通道级缩放：

$$
y=\frac{x}{\mathrm{rms}(x)}\odot g
$$

其中 `g` 对应 `self.weight`。相比 LayerNorm，RMSNorm 不做减均值（centering），只做尺度归一化，因此计算更简单，常用于现代大模型。

## 关键知识点总结
RMSNorm 的核心是“只归一化尺度，不中心化”，在保持效果的同时降低计算开销。`eps` 避免分母过小导致数值不稳定。`keepdim=True` 让归约结果可直接广播回输入形状，是这类归一化实现中的关键细节。
