# [swiglu] swiglu 代码解释笔记

## 原始代码
```python
class SwiGLU(nn.Module):
    """SwiGLU FFN: (xW1) ⊗ swish(xW2) W3  with expansion factor `mult`.
    """
    def __init__(self, dim: int, mult: int = 4, dropout: float = 0.0):
        super().__init__()
        inner = mult * dim
        self.w1 = nn.Linear(dim, inner, bias=False)
        self.w2 = nn.Linear(dim, inner, bias=False)
        self.w3 = nn.Linear(inner, dim, bias=False)
        self.act = nn.SiLU()
        self.drop = nn.Dropout(dropout)
    def forward(self, x):
        a = self.w1(x)
        b = self.act(self.w2(x))
        return self.drop(self.w3(a * b))
```

## 语法用法
`SwiGLU` 继承 `nn.Module`，属于 PyTorch 自定义层的标准写法。`super().__init__()` 会初始化父类内部状态并注册子模块。

`inner = mult * dim` 定义前馈网络的扩展宽度，`mult` 通常取 4 或更大。`nn.Linear(dim, inner, bias=False)` 表示线性投影层，不使用偏置项；该写法在现代 Transformer 中很常见。

`self.act = nn.SiLU()` 是 Swish 激活函数的 PyTorch 实现。`self.drop = nn.Dropout(dropout)` 在训练阶段随机丢弃部分激活值，缓解过拟合。

在 `forward` 中，`a = self.w1(x)` 是主分支，`b = self.act(self.w2(x))` 是门控分支；`a * b` 是逐元素相乘（Hadamard product），最后经过 `w3` 投影回原维度，再做 dropout。

## 维度解读
设输入 `x` 形状为 `(B, T, C)`：
- `B`：batch size
- `T`：序列长度
- `C`：通道维/hidden size，对应代码中的 `dim`

定义 `inner = mult * dim`，因此 `inner = mult * C`。

关键中间变量 shape 变化：
1. `a = self.w1(x)`：`(B,T,C) -> (B,T,inner)`
2. `self.w2(x)`：`(B,T,C) -> (B,T,inner)`
3. `b = self.act(self.w2(x))`：激活是逐元素操作，形状保持 `(B,T,inner)`
4. `a * b`：逐元素乘法，要求两侧形状一致；这里是 `(B,T,inner) * (B,T,inner)`，输出 `(B,T,inner)`
5. `self.w3(a * b)`：`(B,T,inner) -> (B,T,C)`
6. `self.drop(...)`：dropout 不改变 shape，最终输出 `(B,T,C)`

本段没有 `view/reshape`、`transpose/permute`、`matmul/attention` 的显式维度重排，但存在关键“维度对齐约束”：门控乘法前两分支必须同 shape（都为 `(B,T,inner)`），否则无法逐元素相乘。

## 代码逻辑
该模块是 SwiGLU 前馈层。先将输入并行送入两条线性分支：
- 主分支 `w1` 产生内容表示 `a`
- 门控分支 `w2` 经 `SiLU` 激活后得到门值 `b`

然后用 `a * b` 做门控融合：`b` 会按位置与通道调制 `a` 的信息流，保留有用信号、抑制无效信号。接着 `w3` 将扩展维度压回原始维度，便于与残差连接保持一致。最后 `Dropout` 在训练时提升泛化能力。

与传统 FFN（如 `Linear -> GELU -> Linear`）相比，SwiGLU 的门控结构通常在相近参数量下表现更好，因此在很多现代大模型中成为默认 FFN 变体。

## 关键知识点总结
SwiGLU 的核心是“双分支 + 逐元素门控”：一条分支提供内容，一条分支提供门值，二者相乘形成动态调制。维度主线是 `(B,T,C) -> (B,T,inner) -> (B,T,C)`，其中 `inner = mult * C` 决定了前馈层容量。实现上最关键的 shape 条件是门控相乘前两分支必须严格同形状。
